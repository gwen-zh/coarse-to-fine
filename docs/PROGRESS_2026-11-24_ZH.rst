项目进度与接手说明（2026-11-24）
================================

目前能说的结论
--------------

已经确认的成果是：在原作者发布路径上，不改权重，用多次 decoder 调用指导
fine-token 搜索，改善局部骨架几何。两个不参与接受判据的键角误差有独立确认。

自训多尺度表示和生成接口都已实现，也做了 MD 训练和 PAR 预训练模块迁移。
但新生成器还没有可靠超过原作者，构象覆盖与镜像分支仍未解决。最近一次手性
辅助损失的复验是一好一坏，不能把此前单次 18.5% 改善写成稳定升级。

最新数值复验在美东 11 月 10 日 / UTC 11 月 11 日完成。本说明在 11 月 24 日
首次核对已有结果和 Slurm 队列时没有新训练。随后按用户要求继续，已提交独立的
手性速度场残差对照任务 58007793，并在 n041 启动。五项模块测试和真实权重
预检通过，协议已冻结，目前没有最终质量结果。具体见
CHIRAL_VELOCITY_STUDY_2026-11-24.rst。旧 PAR transfer 的评估任务因依赖失败
而 pending，不代表训练还在推进。

一路做过什么
------------

1. 从原模型表示入手：代码审计确认三个码本量化同一个残基级 latent，各层
   独立走共享 decoder。进行了 medium 码本修复与 residual VQ 表示实验。
   重建收益不能直接推出生成收益；不同信息率的表示也不能直接比较优劣。
2. 训练生成器适配：试过 LoRA、条件注入和几何辅助项等。发现准确性、几何、
   多样性之间存在权衡。CE 降低不可靠地转化为解码几何改善；现有相关性观察
   不能证明所有离散模型都存在同一种因果机制。
3. 原路径推理期搜索：固定权重，用真实 decoder 输出评估候选 token，约束
   相对初始输出的漂移，合格才接受，否则返回原结果。参考结构不参与接受。
   这条路线有独立确认，也是目前最适合写进论文/CV 的结果。
4. 自训结构表示：最初为每 4 残基一个 16 维连续 coarse latent、每残基一个
   1024 码本 fine token；训练自己的结构 encoder、EMA 码本和刚体 decoder。
   这版重建可用，但生成质量明显落后，不能把重建精度当成生成精度。
5. 改为局部标架和连续 fine：目前使用物理块中心 M×3，绕过 16 维 coarse
   编码压缩；fine 为标架内 N×8 连续 latent，当前生成路径不再经过 VQ/snap。
   decoder 用残基刚体放置 N/Cα/C，块内 Cα 均值有结构性约束，跨残基肽键
   仍需评估。旧 1024 码本作为历史对照保留。
6. 序列条件多尺度 flow：先从 AA 条件采样 coarse，再在同一个 coarse 条件下
   采样 fine。用五条训练序列的 MD 多帧做过训练。模型会用 coarse，给它更好
   的布局能改善结果，但自己预测 coarse 仍是主要瓶颈。
7. 引入 PAR：接入公开预训练模型和零初始化 AA adapter，先只测 coarse，
   再考虑接自己的 fine flow/decoder。当前只完成 coarse 接口试验，尚未完成
   PAR 的全尺度 L/4→L/2→L 序列条件生成器。
8. 收缩为两蛋白可学性检查：延长固定训练、加 native flow LoRA、检查轨迹及
   手性。模型学会区分两个蛋白，但仍会生成镜像形状。训练目标构造的检查
   未发现反射标签；没有证明具体架构对反射完全盲目。
9. 有向体积辅助损失：探索种子改善，随后两新训练噪声种子的固定复验未通过。
   保留全部结果，关闭这一损失扫描分支，没有采用这些候选权重。

原模型上已确认的收益
--------------------

数据：64 个独立于方法开发、预先筛选的蛋白，每个 8 个构象，共 512 个。
这里的独立不表示从未出现在 ESM3 预训练里，也不是 MD 热力学确认集。

* C–N 异常率：9.50015% → 7.53809%，相对下降约 20.65%。这是接受判据之一，
  所以本身不是独立证据。
* 非门控 CA–C–N 键角 MAE：平均下降 0.14889°，名义 97.5% bootstrap 区间
  [-0.18642, -0.11437]。
* 非门控 C–N–CA 键角 MAE：平均下降 0.15304°，区间 [-0.19491, -0.11557]。
  两个预设端点通过预设多重比较校正。
* 参考 CA RMSD：3.24891 → 3.25096 Å；样本 spread：3.19169 → 3.19545 Å。
  差值区间跨零，只能说未检出变化，不能说证明不退化或系综保持不变。
* 平均改动 fine token 的 1.49237%。保存的计时为原生成约 6.03 秒、额外搜索
  约 20.76 秒/构象；实际使用必须同时考虑开销和硬件口径。

随机位置搜索也有类似键角收益；尚不能声称违例定位优于随机提案。这个确认集
已经用过，之后不能再拿它选参数。方法当前只在原作者 token/decoder 上验证，
尚未证明能直接移植到连续表示或别的模型。

目前的训练与生成图
------------------

表示训练（有真实坐标）::

    已知 N/Cα/C 坐标 X
        ├─ 每 4 个连续残基的 Cα 均值 → C*: M×3
        └─ 按 C* 建局部标架 → fine encoder → F*: N×8
                                      │
                    C* + F* → 自训刚体 decoder → 重建 X

生成器训练（有 AA 和真实结构标签）::

    AA → 冻结 ESM3 的序列特征 H: N×1536
    H + 带噪 C* + 时间 → coarse 速度场 → flow-matching 损失
    H + coarse 条件 + 带噪 F* + 时间 → fine 速度场 → flow-matching 损失

    fine 的训练条件与标签必须对应同一个物理构象；标架变了需要重新编码 fine，
    不能把随机采出的另一个 coarse 与原 fine 标签任意拼成监督对。

实际生成（没有真实结构输入）::

    AA 序列 → AA-only 特征 H
        + coarse 噪声 → coarse flow 迭代 → C: M×3
        + fine 噪声 + H + 同一个 C → fine flow 迭代 → F: N×8
        → 局部标架/刚体 decoder → N×3×3 的 N/Cα/C 坐标
        → 换随机噪声，重复得到多个构象

    PAR 分支目前替换的是 coarse 生成模块；自己的 fine/decoder 保持为接口对照。
    原模型的 fine-token decoder-feedback 搜索是另一条已确认的分支，尚未成为
    这个连续生成器的已验证后处理步骤。

M=ceil(N/4)，末尾不足 4 残基也算一块。fine 维数是每残基 8，不是每块 8。
同一序列可以有不同噪声产生的不同结果，但“有多样性”不等于“系综分布正确”。

最近 PAR 诊断的数字与边界
-------------------------

以下全是两个已反复使用的训练结构：1b2s_E、1ef1_D，均为 90 残基，各一个
固定 MD 帧。RMSD 衡量 23 个 coarse 块中心，不是全链测试集 RMSD。

* AA 条件 uniform-time 模型 1024 步：6.047 Å；同长度但无 AA 对照：14.195 Å。
  说明序列条件有用，不说明跨蛋白泛化成功。
* 固定继续训到 4096 步：相同 32 个采样噪声下 6.047 → 3.746 Å。
  两蛋白平均误差都没过预设 2 Å 门槛，增加采样积分步也没解决问题。
* 新的同预算 LoRA 对照用 64 个共同采样噪声：adapter-only 为 3.34128 Å，
  加 flow LoRA 为 3.31968 Å，增益仅 0.02160 Å；噪声子集方向不一致。
  两边都有 41/128 个输出在允许反射的正交拟合下偏好镜像支路。
* 手性辅助损失最初一次：3.64769 → 2.97259 Å，改善 18.5%，仅探索性。
* 固定复验：2027 为 3.72671 → 3.19819 Å；2028 为 3.70426 → 3.96524 Å。
  一好一坏，未通过预设“两个新 seed 方向均改善”的判据。

这里 seed 改的是训练噪声/时间/旋转/自条件抽样，参数和 Adam 起点相同，
并非两个独立预训练初始化。2026 旧权重新采样的正向结果也不能充当新训练复验。
全部 1280 个请求输出有限且保留，没有筛掉失败样本，没有按结果延长训练。

退化的 seed 2028 在第一个蛋白上多出了净 4 个偏镜像的输出。训练手性 loss
降低并不保证自由采样手性改善；这说明此辅助目标未稳定解决问题，并不证明
“一定是 clipping 的错”或“模型结构注定不行”。默认模型未替换。

接下来按什么顺序做
------------------

1. 新建独立协议，测试有手性信息的速度场残差模块，保持原 velocity-MSE
   目标；与同参数量、不含对应手性构造的模块做控制。交叉积特征是候选假设，
   已实现并提交为任务 58007793，预检通过，尚无最终收益结论。
2. 旋转行为、零初始化回放、真实梯度和参数量验证已通过；预算已冻结为两个
   训练抽样 seed × 三组 × 1024 步。保留全部结果，先看两训练结构可学性。
3. 过门槛后另开 MD 多帧泛化/覆盖实验，检查准确性、几何、多样性、覆盖和耗时。
   目前 MD 训练虽有 2264 帧，却只来自五条序列，泛化证据很有限。
4. 保持原路径搜索结果的写作推进；准备在相同蛋白、指标和计算预算下比较。
   不把 coarse 训练误差与另一个测试集的全链 RMSD 混在一起。
